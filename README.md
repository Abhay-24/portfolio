# PHP Developer Portfolio

A premium, responsive single-page PHP portfolio with:
- Animated particle background
- Scroll reveal animations
- 3D card tilt interaction
- Cursor glow
- Scroll progress indicator
- Responsive mobile navigation
- Animated technology marquee
- PHP contact form handler
- No frontend framework required

## Run locally

Using PHP's built-in server:

```bash
php -S localhost:8000
```

Then open:

http://localhost:8000

## Before publishing

1. Open `index.php`.
2. Replace `your-email@example.com` with the real email address.
3. Replace the LinkedIn and GitHub `#` links with real profiles.
4. If your hosting does not support `mail()`, use SMTP/PHPMailer.
5. Add your own project URLs/screenshots if you want each project card to link to a live case study.

## Suggested production stack

PHP 8+, Apache/Nginx, HTTPS, SMTP, Git and a simple deployment pipeline.
